# WS 基本规则

本文整理当前已提供的 WS 规则描述，用于说明双方玩家进行伤害判定、时计区结算和败北条件的基本流程。

## 1. 卡组构成

游戏开始时，双方玩家各自拥有 50 张卡牌的卡组：

| 卡牌类型 | 数量 |
| --- | ---: |
| 高潮卡 | 8 张 |
| 普通卡 | 42 张 |
| 合计 | 50 张 |

## 2. 伤害与伤害判定

游戏过程中，玩家可以通过各种操作对对方玩家造成伤害。造成伤害前，需要先声明本次伤害的数量。

伤害被声明后，由受到伤害的一方进行伤害判定。

### 2.1 判定流程

受到伤害的一方从自己的卡组顶开始，逐张翻开卡片，直到满足以下任一条件为止：

1. 翻开的普通卡数量达到声明的伤害数；或
2. 出现高潮卡。

翻卡过程中，判定按照以下规则执行：

- **出现高潮卡**：立即停止翻卡，本次伤害判定为**未命中**。
- **未出现高潮卡，且达到声明的伤害数**：停止翻卡，本次伤害判定为**命中**。

### 2.2 判定结果

伤害判定结束后，翻开的卡片按照判定结果处理：

- **伤害命中**：所有翻开的卡片进入受到伤害一方的**时计区**。
- **伤害未命中**：所有翻开的卡片进入受到伤害一方的**弃牌区**。

其中，伤害未命中时，已经翻开的高潮卡也一并进入弃牌区。

## 3. 卡组耗尽时的处理

在伤害判定过程中，如果受到伤害一方的卡组没有剩余卡牌，则立即执行以下步骤：

1. 如果该玩家的弃牌区没有可洗回的卡牌，则该玩家立即宣告败北并结束游戏。
2. 否则，将该玩家的弃牌区卡片洗切，并放回该玩家的卡组区。
3. 从洗好的卡组顶取出一张卡片，直接放入该玩家的时计区。
4. 无论该卡是高潮卡还是普通卡，均不因高潮卡而取消本次伤害判定。
5. 继续进行本次伤害判定。

## 4. 时计区结算

每位玩家的时计区有 7 个位置。

当受到伤害一方的时计区卡牌数量达到或超过 7 张时，需要立即进行结算：

1. 从时计区选择 1 张卡，放置到该玩家的等级区；一般不会选择高潮卡进入等级区。
2. 将时计区中剩余的所有卡牌放置到该玩家的弃牌区。

## 5. 败北条件

当任意一名玩家的等级区卡牌数量达到或超过 4 张时，该玩家立即败北，游戏结束。

## 6. 规则流程摘要

1. 玩家声明对对方造成一定数量的伤害。
2. 对方从卡组顶逐张翻牌。
3. 出现高潮卡时，伤害判定未命中；未出现高潮卡且翻牌数量达到声明伤害数时，伤害判定命中。
4. 根据判定结果，将本次翻开的全部卡牌放入时计区或弃牌区。
5. 判定过程中卡组耗尽时，若弃牌区没有可洗回的卡牌则立即败北；否则洗切弃牌区补充卡组，并将卡组顶的一张卡放入时计区后继续判定。
6. 时计区卡牌达到或超过 7 张时，将其中 1 张放入等级区（一般不会选择高潮卡），其余卡牌放入弃牌区。
7. 任意玩家的等级区达到或超过 4 张时，该玩家立即败北，游戏结束。
